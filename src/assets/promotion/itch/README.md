# The itch.io page (#138)

`itch-background-2560x1600.jpg` (or the `.png`) is the page background: two
in-game panels, CM-07 firing the minigun on the left and a guard squad with
the Goliath charging on the right, framed in the game's UI language (neon
rails just outside itch's 960 px column, cut-corner brackets, ruler ticks,
the scrap hex nut, gold chevrons), the dusk sky between them, fading into the
page colour. Composed so the subjects sit in the bands a 1920 px screen shows
beside the column (`itch-page-preview-1920.png`); a wider screen shows more.
